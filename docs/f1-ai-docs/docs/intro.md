# F1 AI Commentary Handover Site

This site is the central handover reference for the F1 AI Commentary project.
It is designed to help the next team take ownership quickly, with clear links to
delivery evidence, product artefacts, and API documentation.

## Purpose

- Provide a fast onboarding path for new maintainers
- Preserve implementation evidence and sprint history
- Keep visual design artefacts and API references discoverable
- Document what to maintain, where to find it, and what to verify first

## Start Here

- Read the [Handover Guide](/docs/handover) for the recommended takeover sequence.
- Review [Kanban and Delivery Tracking](/docs/agile/kanban) for sprint context.
- Check [API Reference](/api) for current endpoint contracts.
- Use the [Asset Gallery](/docs/assets/overview) for wireframes, poster, and visual assets.
- Scan [Sprint Minutes](/sprints) for recent decisions and changes.

## What This Site Covers

### Handover and Operations

- Handover checklist and takeover order
- Key evidence pages for project continuity
- Practical references for maintenance and updates

### Design and Visual Artefacts

- Wireframes in newest-first order
- Poster and supporting visual material
- Team assets centralized in stable URLs

### Delivery and Agile Evidence

- Kanban board snapshots and live board link
- Sprint update log for timeline continuity
- Ongoing evidence trail for handover confidence

### API Documentation

- OpenAPI-backed reference page
- Interactive endpoint exploration for integration checks

## Maintenance Guidance

- Update pages whenever implementation or process changes
- Keep links to source evidence (Kanban, sprint logs, API schema) current
- Prefer short, explicit notes focused on continuity for incoming teams

## Maintenance Guidance

- Keep pages concise and update them when implementation changes
- Prefer linking evidence (PRs, Kanban items, test output) where relevant
- Record decision context, not just final outcomes
